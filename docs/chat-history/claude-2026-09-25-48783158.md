**How it behaves:**
- **Licence first:** the licence, terms URL and download size come from two Hugging Face API calls, before any model file is requested.
- **Only runtime files:** the config, the `.onnx` files and their data, tokenizer files, the chat template and `config.json`, from the named folder only.
- **Fingerprints:** SHA-256 for large files, the git blob SHA-1 for small ones. A file that fails is deleted.
- **Refusals:** gated, private or missing repos, and malformed names (anything outside `owner/name` with letters, digits, `.`, `_`, `-`; no `..` or `--`).
- **Pinning:** the first call records the commit it resolved to, so later starts work offline. A 40-character commit given as `version` is used exactly.
- **Where files go:** `&lt;root&gt;/hf--owner--name[--folder]--&lt;first 12 chars of the commit&gt;`.
- **Mirror:** `TECHIERAG_MODEL_BASE_URL` does not apply to Hugging Face names; the name is the source.
- **Memory check:** KV bytes per token = layers × KV heads × head size × 2 × 2 bytes, read from `genai_config.json`. Gemma comes to 26,624.
