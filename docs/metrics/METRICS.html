Read the "Runs observed" column first. Fan-out can only be seen on a tree-scope run. On a main-scope run nobody looked at the subagents, so 0 there means not looked, not none ran. Every unobserved run in this table is unobserved because it was not tree scope; none predate the field. Of the nine runs added since the last snapshot, five are tree scope (the 2026-10-11 metrics-report run, three 2026-10-11 fix-issues runs and one 2026-10-11 verify-phase run). Only the metrics-report run spawned a subagent. The three 2026-10-15 runs (two triage-and-fix, one verify-phase) were main scope and the 2026-10-11T09:08:01Z verify-phase run had no window, so those four add nothing to these figures.

Declared vs measured. subagents is what a task wrote about itself; subagent_runs is counted from the harness's own records. Where they differ, the measured one is right. Tasks under-report: in build-phase, handoff-phase and day1-brownfield more subagents ran than were declared, and verify-phase (5) and metrics-report (3) ran subagents they never declared.

\* The fix-issues and triage-and-fix declarations also hold none and prose, not agent kinds (none (fixed inline), and a note split by the tool into several entries). The tool counts each of those as a declared subagent, which is why the declared count is higher than the measured one there. The field takes agent kinds, not a description of the work.
